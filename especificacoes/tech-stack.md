# Stack técnica

## Base escolhida
- Next.js
- TypeScript
- SQLite

## Finalidade
- Frontend moderno e performático para site institucional
- TypeScript para manutenção e escalabilidade do código
- SQLite como banco leve para o ambiente inicial do projeto

## Observações do projeto
- Site responsivo para navegadores modernos
- Compatível com dispositivos móveis
- Estrutura preparada para exibir cursos, matrizes curriculares e notícias
- Área administrativa com login para cadastro de notícias
